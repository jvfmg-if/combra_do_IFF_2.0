# 🐍 Combra do IFF — Snake Game

Jogo da cobrinha (*Snake Game*) desenvolvido colaborativamente por estudantes do primeiro ano do Curso Técnico em Informática Integrado ao Ensino Médio, como projeto interdisciplinar das disciplinas de Introdução à Programação de Computadores e Banco de Dados.

O projeto foi construído com **Python** e **Pygame**, com sistema de autenticação de usuários e ranking de pontuações persistido em **SQLite**, integrado a uma interface web construída com **Flask**.

## 🎮 Sobre o projeto

O desenvolvimento seguiu a metodologia de Aprendizagem Baseada em Projetos (ABP), ao longo de oito semanas, com os estudantes assumindo diferentes frentes de trabalho: lógica do jogo, design gráfico, sonorização, interface web e banco de dados.

O jogo foi apresentado publicamente em um evento acadêmico de divulgação científica, onde recebeu feedback de mais de uma dezena de participantes externos ao curso.

## 🛠️ Tecnologias utilizadas

- **Python** — lógica principal do jogo
- **Pygame** — engine gráfica e de entrada
- **Flask** — interface web (cadastro, login e ranking)
- **SQLite** — persistência de dados de usuários e pontuações
- **Replit** — ambiente de desenvolvimento colaborativo

## ▶️ Como executar

```bash
git clone https://github.com/jvfmg-if/combra_do_IFF_2.0.git
cd combra_do_IFF_2.0
pip install -r requirements.txt
python app.py
```

Acesse `http://127.0.0.1:5000` no navegador.
